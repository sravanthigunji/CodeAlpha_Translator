# CodeAlpha Language Translation Tool

A simple language translation tool built using Python.  
This application allows users to enter text, choose source and target languages, and get translated output instantly.

## Features
- User-friendly interface
- Select source and target languages
- Translate text instantly
- Displays translated output clearly
- Supports multiple languages

## Technologies Used
- Python
- Tkinter
- Deep Translator / Google Translator API

## How It Works
1. Enter text in the input box
2. Select source language
3. Select target language
4. Click Translate button
5. View translated text instantly

## Run the Project

```bash
python app.py
```
